# Project Rules

This project is a Laravel Inventory Management System with POS, Data Analytics, and Decision Support.

## General Rules
- Analyze the existing code before making changes.
- Do NOT modify working features unless I explicitly request it.
- Only edit files that are necessary.
- Explain which files will be modified before editing them.
- Ask for approval before creating or deleting files.
- Follow Laravel 12 best practices.
- Reuse existing controllers, models, migrations, Blade components, and routes whenever possible.
- Preserve the current UI design unless instructed otherwise.
- Keep code clean and well-commented.

## Database
- Never modify migrations unless requested.
- Never delete tables or columns.
- Use Eloquent relationships correctly.

## UI
- Match the existing Bootstrap styling.
- Keep responsive behavior.
- Do not redesign existing pages.

## Responses
- Before coding, explain your implementation plan.
- After coding, summarize what changed.
- If a request is ambiguous, ask for clarification instead of guessing.
